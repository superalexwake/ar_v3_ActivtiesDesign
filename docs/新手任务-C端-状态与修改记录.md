## 2026-10-07（六）点「前往」后返回，回到离开时的位置（全站，含所有活动/任务页）
依据（用户原话）：「每个活动或者任务的点击前往后的返回按钮，点击完后应该回到上一次的地方」。

- 改法：路由（router/index.ts）改为——返回/后退时恢复离开时的滚动位置（列表数据是异步的，等页面撑到够高再滚，最多等 3 秒）；新进入的页面仍回顶部；同一页仅地址栏参数变化（切页签）不动滚动位置。
- 影响面：全站统一生效，不只新手任务；所有「前往」类按钮（每日/每周任务、新手任务、活动卡等）返回后都停在原位置、原页签。
- 验证：编译通过；手机尺寸 5190 实测——每日任务页滚到 300 点「去完成」，返回后仍在每日任务、位置 300；新手任务点「前往完成」跳充值页，返回后仍在新手任务、位置还原。
